# ZENnie — Stress Management & Well-Being Mobile App

A cross-platform mobile application developed using Flutter and Dart to support FCSIT students' mental well-being and stress management.

## 🚀 Features
- Mood tracking & wellness activity recommendations
- Real-time backend database using Firebase
- Hugging Face API integration for automated data fetching
- User Acceptance Testing (UAT) validated with 50 active users

## 🛠️ Tech Stack
- **Framework:** Flutter (Dart)
- **Backend:** Firebase Authentication & Cloud Firestore
- **API:** Hugging Face API
- **Design:** Figma (UI/UX Mockups & Interactive Prototypes)
